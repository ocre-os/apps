# Instrucciones para la persona participante

Estamos probando la facilidad de uso de una herramienta, **no tus habilidades**. La participación es voluntaria y puedes detenerla en cualquier momento.

Te daremos **dos situaciones ficticias**. Con una usarás PRISMA (https://apps.ocre.mx/prisma/) y con la otra tu método habitual: una libreta, notas, etc. Sigue el orden asignado. No consultes internet ni asistentes de IA.

En cada situación, escribe el problema, al menos un hecho concreto y **de dónde viene ese dato**. Puedes añadir una hipótesis o una comprobación futura si te resulta natural, pero no hagas pruebas físicas ni cambies datos reales.

Después intenta encontrar tu análisis en PRISMA y explicar qué falta saber. Finalmente descarga un respaldo JSON y recupéralo en otro perfil de navegador, con ayuda solo para abrir ese perfil, no para usar PRISMA.

Unos siete días después te pediremos encontrar el análisis otra vez. No hace falta memorizar botones.

No uses nombres reales, cuentas, teléfonos, clientes o archivos confidenciales. Si algo resulta confuso, dilo: eso es parte de la evaluación.
